# Eleris.RawNet

A pure managed .NET library to read camera raw files, starting with the Nikon NEF format: metadata without decoding any
pixel, the embedded JPEG preview, and the raw sensor mosaic. net10.0, no dependency, no native code, compatible with
trimming and NativeAOT.

**Status: pre-release.** The first version is being built; the API is not stable before 1.0.

The documentation is in the [repository](https://github.com/sputier/raw-net).
